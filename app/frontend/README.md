# AquaInsight dashboard

From the repository root, run `python -m app.api` in the project Python environment. In a second terminal, change to `app/frontend`, run `npm ci` and `npm run dev`, and open the local URL printed by Vite. Use Node 22.12 or later. Vite forwards `/api` requests to the local Python server on port 18741.

The assessment accepts the four frozen raw measurements. It uses the inclusive plausible ranges in the data dictionary so valid measurements outside the historical sample can be entered. The Python API validates the sample and transforms it with the preprocessing steps from `models/best_model.pkl`. Generate prediction submits the sample to the cached frozen model and Phase 7 local SHAP explainer. Prediction and Explainability show results for that submission. Editing or resetting measurements clears those results. Parameter Analysis shows the configured references for the four raw measurements and derived log fecal coliform. Decision Support uses the Phase 8 SHAP-to-rules output for the same submission. The provisional uncertainty cutoff is a top-class model probability below 0.60. Model probabilities are uncalibrated.

Run `npm run build` for a production build. To verify all sections in Chromium, run `npm run test:e2e` with the project Python interpreter on PATH, after installing the Playwright Chromium browser with `npx playwright install chromium`. On Windows the test configuration uses installed Microsoft Edge.

Overview and Historical Trends require the configured labeled CPCB CSV. Generate it with the Phase 1 join and WQI labeling pipeline (see data/README.md). The local dataset contains monthly sampling dates in 2021. The trend filters select observations by state and station. Monthly parameter means exclude missing measurements; class counts include all dated labeled observations in the selection.
